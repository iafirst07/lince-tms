# Massa de referência editável

Arquivos fictícios para digitar/colar nos formulários. Não são importados automaticamente nem recebem autorização de produção.

`quote.json`: dois volumes com pesos e medidas individuais. Alterações exigem cotação nova antes de criar/editar o pedido.

`import.csv`: conteúdo aceito pelo formulário Importar pedidos, sem cabeçalho: número do pedido; frete cobrado. A cotação, seus volumes, o destino e a janela selecionados no formulário valem para cada linha. O importe primeiro gera prévia; somente linhas elegíveis podem ser confirmadas.

Use identificadores novos a cada exercício. Consultar um cenário não apaga nem reseta o anterior.
